填谱面印的号，跳转就按它

跳转/高亮显示的「第几小节」用的是谱面印刷号。数字版 PDF 导入后会自动按谱面印的号对齐；吉他谱等文字层里混满品格数字的谱子，软件用「多页互相印证」投票过滤噪声。点「自动读谱面小节号」会重读并用印证结果整体覆盖（包括之前填错的值）。扫描件没有文字层时无法读号，请在上方「本页第1格谱面小节号」手动填，点「对齐」即可，后续页自动顺延并自动保存。

手机传谱

手机用浏览器打开下面这个链接，选 PDF / 图片上传；电脑在这下方「收件箱」点「打开」即可导入。

安卓装成应用后：在 B站 / 微信 / 文件管理里点「分享」→ 选 ScoreTurner，或点「用其他应用打开」直接选它，谱子直接进收件箱，不用先下载。iPhone 不支持此通道，请用下方的选择文件或粘贴链接。

  1. 用手机 Chrome（安卓）打开上面的链接
  2. 点右上角「⋮」菜单 → 「添加到主屏幕 / 安装应用」（或地址栏右边的「＋/下载」图标）
  3. 装完后从桌面打开 ScoreTurner，再去 B站/文件管理分享或「打开方式」选它
📤 点此从手机选择乐谱上传PDF 或图片都行 · 会让你从「文件 / 微信 / 相册 / 相机」里选

手机上的谱子若还在微信里，先长按 → 保存到手机 / 用其他应用打开，再到这里就能选到了。
